# Click Counter

My first vibe coding project: a counter you can increase, decrease, and reset.

## What it uses
- **HTML** (`index.html`): the structure (title, number, buttons)
- **CSS** (`style.css`): the look (colors, layout, animations)
- **JavaScript** (`script.js`): the behavior (what happens when you click)

## Features
- `+` / `−` buttons and a Reset button
- Green when positive, red when negative
- Arrow keys ↑ / ↓ work too
- Remembers your count after a page refresh (via `localStorage`)

## How to run it
Double-click `index.html` to open it in your browser. No installation needed.
